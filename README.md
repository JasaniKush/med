# 🏥 MedBuddy – AI Medical Document Simplifier

MedBuddy is an AI-powered healthcare web application that helps users understand medical prescriptions and discharge summaries in a simple and structured format.

Built for emergency use, MedBuddy allows users to upload a document and instantly get clear, patient-friendly insights — without requiring login.

---

## 🚨 Core Principle

This is an **emergency-use application**.

Users can:
- Open the app
- Upload a document
- Get results instantly

❌ No forced login  
✅ Guest-first experience  

---

## 🎯 Problem Statement

Medical documents are often:
- Complex
- Hard to understand
- Filled with technical terms

MedBuddy solves this by:
- Extracting text from prescriptions
- Converting into simple explanations
- Structuring information for easy understanding

---

## ⚙️ Features

### 📥 Instant Upload (No Login Required)
- Upload PDF or image
- Immediate processing

---

### 🧠 AI-Powered Analysis

Generates structured output:

1. Extracted Original Text  
2. Plain-language Diagnosis  
3. Medication Schedule  
4. Side Effect Alerts  
5. Follow-up Checklist  
6. One-line Family Summary  
7. Original vs Simple Comparison  
8. Voice Output  

---

### 🔊 Voice Support
- Converts summary into speech
- Supports multiple languages:
  - English
  - Hindi
  - Gujarati

---

### 🔐 Optional Authentication
- Login/Signup only when needed
- Used for:
  - Saving reports
  - Viewing history

---

### ☁️ Secure Storage
- Files stored in private storage
- Session-based access
- Auto-expiry for guest data
